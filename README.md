# Collage-2.0

Application de gestion des panneaux d'affichage libre. Localisez les panneaux, enregistrez les collages, le nombre d'affiches et les dates de passage. Suivez leur état, consultez l'historique et créez des itinéraires optimisés pour organiser les tournées.

## Tournez l'affichage

`index.html` contient l'application complète, en un seul fichier :

- deux campagnes : Nouvelle Energie et #RemueMéninges
- collages, constats (conforme, à contrôler, décollé, recouvert par un parti)
- historique signé par personne, avec date et heure
- tableau de bord statistique et tournée avec lien Google Maps

L'application publiée sur Claude utilise le stockage partagé et l'identité des trois membres invités. Ce fichier en dépend : ouvert hors de Claude (par exemple sur GitHub Pages), il affiche « Accès privé » et n'enregistre rien.
